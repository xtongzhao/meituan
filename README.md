# 周末出逃 · 城市探索指南

一个可本地运行的中文网页，用兴趣、预算、同行人数和天气情景筛选上海周末活动。

## 本地打开

下载或克隆本仓库，直接用浏览器打开 `index.html` 即可。不需要安装 npm 依赖、编译或部署，图片也已保存在项目内。

如果希望更稳定地使用本机保存和复制功能，可在项目目录执行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8000 。按 Ctrl+C 停止服务。这个地址只用于本机访问。

## 功能

- 按兴趣、预算和同行人数推荐活动。
- 切换晴天、多云或雨天情景，雨天筛选室内活动。
- 将活动加入出逃清单并记录打卡。
- 生成、复制组队邀请文字。
- 编写个人攻略，保存到本机并复制分享。

活动、价格和天气均为演示数据，不代表实时信息；组队为邀请文字分享，不包含真实报名或多人房间。个人清单和手记保存在当前浏览器中，不会自动同步到其他设备。浏览器限制本地文件存储或剪贴板时，建议使用上面的本地服务方式。
